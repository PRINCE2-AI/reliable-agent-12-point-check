One rule. Every point logs pass or fail with the artifact that proves it - not a status message. If a point cannot run, it fails. There is no skip.
  1. 1Guardrail is registered on the execution path
  2. 2Guardrail sees normalized input
  3. 3Tool manifest hash matches the pinned hash
  4. 4Tool schema diff is reviewed before load
  5. 5Output set is asserted, not just the exit code
  6. 6Exit code is not the health signal
  7. 7Eval reports worst case, not the average
  8. 8Eval runs against a production-like environment
  9. 9Timeout and retry behavior tested on a failing tool
  10. 10Permissions diffed against the last deploy
  11. 11Kill switch tested end to end
  12. 12Canary with one known-bad case runs after deploy
